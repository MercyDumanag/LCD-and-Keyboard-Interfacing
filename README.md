### LCD-and-Keyboard-Interfacing
This project exercise focused on designing and implementing an LCD and keypad interfacing system using the STM32F407 microcontroller. 
The objective of this project is to understand the operation modes of an LCD, to interface and program an LCD, and to interface a 4x4 keyboard (keypad) to the STM32F407ZGT6-based Development Board.
By completing this project, practical experience is gained in programming STM32-based microcontrollers using Embedded C/C++ within the STM32Cube IDE environment. The exercise provides insight into the interaction between software logic and hardware interfaces, including button input reading, LED output control, and real-time response using polling techniques.
